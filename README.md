# SocialSphere — Mini Social Network

A front-end social-network prototype built with **HTML, CSS, and vanilla JavaScript**. The interface demonstrates a profile sidebar, post composer, image preview, privacy toggle, and notification interactions.

## Features

- Social feed layout with a post composer
- Character counter for post text
- Image selection and local preview
- Profile card with post, follower, and following metrics
- Public/private interface toggle
- Notification badge interactions
- Responsive glass-style UI and custom styling

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/junaidkhan051/Mini-Socail-Network.git
   cd Mini-Socail-Network
   ```
2. Open `social Media.htm` in a modern browser.

```text

```

## Important Scope Note

This is a **front-end prototype**, not a production social network. Posts and notification interactions are handled in the browser; the project does not currently provide a backend, real authentication, or persistent multi-user data.
